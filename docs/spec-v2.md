# 飲み会会計アプリ 仕様書 (現行 v2)

---

## 1. アプリ概要

**用途**: サークル・職場・友人グループなどの飲み会・イベントで、幹事が会計をまとめるためのスマホ向けWebアプリ

**配布形式**: GitHub Pages 上の静的SPA（インストール不要、URLを共有するだけで使える）

**技術スタック**:
| 項目 | 採用技術 |
|------|---------|
| フレームワーク | React 18 + TypeScript + Vite |
| スタイル | Tailwind CSS v4 |
| 状態管理 | Zustand v5 |
| データ保存 | localStorage（ブラウザローカル、単一イベント） |
| PDF出力 | @react-pdf/renderer v4（NotoSansJP フォント） |

---

## 2. データモデル

### PartyConfig（会の基本情報）
| フィールド | 型 | 説明 |
|-----------|-----|------|
| title | string | イベントタイトル（例: 2026年度 歓迎会） |
| date | string | 開催日（ISO日付文字列） |
| totalPayment | number \| null | 総支払金額 |
| headcount | number \| null | 割り勘計算用の人数（参加者リストとは独立） |
| memo | string | 店名・場所などのメモ |
| notes | string | 自由記述備考欄 |

### Group（グループ）
| フィールド | 型 | 説明 |
|-----------|-----|------|
| id | string | UUID |
| name | string | グループ名（例: 1年生、2年生） |
| color | 'purple' \| 'blue' \| 'green' \| 'orange' \| 'pink' | バッジ色 |
| defaultAmount | number \| null | 一括設定金額 |

### Participant（参加者）
| フィールド | 型 | 説明 |
|-----------|-----|------|
| id | string | UUID |
| name | string | 参加者名 |
| groupId | GroupId \| null | 所属グループ（未割り当て可） |
| amount | number \| null | 徴収金額（null = 未入力、0とは別） |
| isPaid | boolean | 徴収済みフラグ |

## 3. 機能一覧

### 3-1. 会の情報管理
- タイトル・日付・メモの入力
- 総支払金額の入力（カンマ区切り表示）
- **割り勘計算**: 総額÷人数 → 1人あたり金額をリアルタイム表示（切り上げ）
- 人数を入力すると参加者リストに空白行を自動追加

### 3-2. グループ管理
- グループの追加・削除（最大5色: purple / blue / green / orange / pink）
- **一括金額設定**: グループに金額を設定 → 全メンバーに一括反映
- グループ小計・平均額の表示
- **提案金額表示**: 端数がある場合 100円切り上げの提案 (`💡`)
- **残り計算表示**: 1グループの金額を固定したとき、他グループ/未割り当て者の1人あたり金額を表示 (`📊`)

### 3-3. 参加者管理
- 名前・グループ・金額の個別入力（全てインライン編集）
- 名前の左にグループカラードット表示 (`●`)
- 行内でグループを後から変更できるセレクター
- 徴収済みトグル（✓ ボタン、チェックで薄く表示 + 取り消し線）
- 参加者の削除
- 金額: 未入力時はオレンジ背景、入力済みはグレー背景

### 3-4. 精算サマリー（リアルタイム）
- 支払合計 / 徴収合計
- 不足・余剰・ちょうど の3状態（色分け: 赤・緑・青）
- 参加者数 / 徴収済み人数 / 未入力人数

### 3-5. PDF出力
- ボタン1タップでPDF生成（NotoSansJPフォントで日本語対応）
- 内容: 会タイトル・日付・メモ / 精算サマリー / グループ別参加者明細
- 新しいタブで開く → iOSのネイティブPDFビューア → 共有シートでLINE/メール送信可能

### 3-6. その他
- **自動保存**: 全操作がlocalStorageに自動保存（ページ再読み込みでも復元）
- **リセット**: 確認モーダル付きで全データ削除
- **備考欄**: 自由記述テキストエリア

## 5. 現行版の制限・課題

| # | 課題 | 詳細 |
|---|------|------|
| 1 | **単一イベント** | 過去イベントを保存・切り替えする機能がない |
| 2 | **PDF共有導線** | PDF新規タブで開くだけ。LINEへの直接シェアができない |
| 3 | **参加者の並び替え** | ドラッグ&ドロップ等での順序変更ができない |
| 4 | **グループ数制限** | 色が5種類しかない（それ以上のグループは同色になる） |
| 5 | **名前一括入力** | 名前をまとめて貼り付けて追加する機能がない |
| 6 | **端数処理** | 100円切り上げ固定（1円・10円単位の選択不可） |
| 7 | **オフラインPDF** | NotoSansJPをCDNから読み込むためオフライン時にPDF日本語が崩れる可能性 |
| 8 | **UI密度** | 小さい文字・狭い入力欄が多く、指が太い人は操作しにくい |
| 9 | **ガイダンス不足** | 初回起動時に使い方がわからない |
| 10 | **テキスト共有** | PDFではなくLINEに貼れるテキスト形式での出力がない |

## 6. v3 に向けた改善案（優先度順）

### 高優先度
1. **テキストコピー機能** — PDF不要でLINEに即貼れる精算サマリーをコピー
2. **UI大型化** — タップターゲットを最低44pxに統一、文字を大きく
3. **名前の一括入力** — 改行区切りでまとめて貼り付け追加
4. **端数処理選択** — 1円 / 10円 / 100円 単位を選べるように

### 中優先度
5. **過去イベント履歴** — 複数イベントをlocalStorageで保存・切り替え
6. **参加者並び替え** — 長押しドラッグで順序変更
7. **グループ色追加** — 8色以上に拡張
8. **フォント内蔵PDF** — CDN依存をなくし確実に日本語表示

### 低優先度
9. **LINEシェア** — LINE URL Scheme での直接シェア
10. **初回チュートリアル** — 初回起動時の簡易ガイド
11. **PWA対応** — ホーム画面に追加してネイティブアプリ風に
